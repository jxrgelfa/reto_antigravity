# AGENTIC SKILLS (PODA REALIZADA - CLASE 06)

Este directorio alberga las habilidades especializadas de Antigravity 2.0 conservadas tras la auditoría holística y poda inteligente basada en los 6 documentos de `docs/contexto/`.

## 🟢 Skills Conservadas (Frontend & SDD):
1. **tailwind-ui**: Utilidades de TailwindCSS v3, diseño responsive mobile-first y estados hover/focus.
2. **html5-semantic-a11y**: Estructuración semántica, accesibilidad web (WCAG 2.1), roles ARIA y contraste.
3. **vanilla-dom-interactivity**: Manipulación de clases del DOM, gestión de modales, listeners de teclado y eventos touch.
4. **sdd-gentle-flow**: Metodología Spec-Driven Development adaptativa (explore, propose, apply, verify).

## 🔴 Skills Podadas / Eliminadas (Incompatibles):
- Backend: `node-express`, `python-fastapi`, `django`, `docker`, `postgresql`, `mongodb`.
- Heavy Frameworks: `react-nextjs`, `vue3`, `angular`, `svelte`.
- Mobile/Desktop nativo: `flutter`, `react-native`, `electron`.
